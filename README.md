\# nassauTickets



\## Descricao



O nassauTickets e um sistema web para gerenciamento de atendimento e controle de tickets em um laboratorio de analises clinicas.



O sistema tem como objetivo organizar o fluxo de atendimento, permitindo a emissao de senhas, o gerenciamento das filas, a chamada dos clientes pelos atendentes e a exibicao das senhas chamadas em um painel.



\## Objetivo



Desenvolver uma aplicacao web capaz de controlar o atendimento de clientes em um laboratorio de analises clinicas, organizando diferentes tipos de atendimento e permitindo o acompanhamento das chamadas.



O sistema devera considerar as regras de prioridade, registrar os atendimentos e disponibilizar informacoes para acompanhamento e auditoria.

\## Instalacao



Clone o repositorio:



git clone https://github.com/Luizamenezesc/nassauTickets.git



Entre na pasta do projeto:



cd nassauTickets



Entre na pasta do frontend:



cd frontend



Instale as dependencias:



npm install



\## Execucao



Para executar o frontend em ambiente de desenvolvimento:



npm run dev
